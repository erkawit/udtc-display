# UDTC Display Manager
ระบบจัดการส่วนแสดงผล (ฝังด้วย `<iframe>`) และหน้าเว็บเผยแพร่ข้อมูล — ศาลจังหวัดอุดรธานี

ใช้ **Node.js อย่างเดียว** ไม่ต้องใช้ XAMPP / Apache / AppServ / MySQL และไม่ต้อง `npm install`

---

## 0. เลือกรูปแบบการติดตั้ง

| รูปแบบ | เหมาะกับ | ต้องติดตั้ง |
|---|---|---|
| **เครื่องแม่ข่ายภายใน** (หัวข้อ 1) | ใช้ภายในหน่วยงาน ไม่ต้องการให้คนนอกเห็น | Node.js อย่างเดียว ไม่ต้อง `npm install` |
| **ออนไลน์: GitHub + Vercel + Neon + Vercel Blob** | ต้องการให้คนนอกเห็นภาพ และใช้โค้ด HTML + CSS หรือ iframe บนเว็บศาล | ดูไฟล์ **[DEPLOY-VERCEL.md](DEPLOY-VERCEL.md)** |

ระบบเลือกโหมดเองจากตัวแปรแวดล้อม:
- `DATABASE_URL` → ใช้ฐานข้อมูล Neon แทน `data/db.json`
- `BLOB_READ_WRITE_TOKEN` → ใช้ Vercel Blob แทนโฟลเดอร์ `uploads/`
- `SESSION_SECRET` → ใช้ลงลายเซ็น cookie เข้าสู่ระบบ (ถ้าไม่ตั้ง บนเครื่องภายในจะสร้าง `data/session.key` ให้เอง)

ใส่ไว้ในไฟล์ `.env` ข้างๆ `server.js` ได้ (ดูตัวอย่างใน `.env.example`) ย้ายข้อมูลเดิมขึ้นคลาวด์ด้วย `node scripts/migrate-to-cloud.js`

## 1. ติดตั้งบนเครื่องแม่ข่าย (Server) ให้เครื่องลูกข่ายใช้งานได้

**ฝั่งเครื่องแม่ข่าย (Windows / Windows Server)**
1. ติดตั้ง **Node.js 18 ขึ้นไป** (แนะนำ LTS) จาก https://nodejs.org
2. คัดลอกโฟลเดอร์ `udtc-display` ไปวางในตำแหน่งถาวร เช่น `D:\udtc-display` (อย่าวางไว้บน Desktop หรือ Downloads)
3. (ถ้าต้องการ) แก้พอร์ตใน `config.json` — ค่าเริ่มต้นคือ `8090`
4. **คลิกขวา `install-server.bat` → Run as administrator** สคริปต์จะ
   - เปิดพอร์ตใน Windows Firewall ให้เครื่องลูกข่ายเข้าถึงได้
   - ตั้งให้ระบบทำงานเบื้องหลังอัตโนมัติทุกครั้งที่เปิดเครื่อง (ไม่ต้อง login, ไม่มีหน้าต่างค้าง, ถ้าหยุดทำงานจะเริ่มใหม่เอง)
   - เริ่มระบบทันที และแสดงที่อยู่ให้เครื่องลูกข่ายใช้
5. เข้าหลังบ้าน → **ตั้งค่าเว็บไซต์** → กรอก “ที่อยู่เว็บไซต์สำหรับเครื่องลูกข่าย” เช่น `http://192.168.1.10:8090`
   (ใช้สร้างโค้ด iframe และลิงก์ให้ถูกต้อง แม้แอดมินจะเปิดหลังบ้านจากตัวเครื่องแม่ข่ายผ่าน localhost)

**ฝั่งเครื่องลูกข่าย (Client)** ไม่ต้องติดตั้งอะไร เปิดเบราว์เซอร์แล้วเข้า
- หน้าเว็บไซต์: `http://IP-เครื่องแม่ข่าย:8090/`
- หลังบ้าน: `http://IP-เครื่องแม่ข่าย:8090/admin` — บัญชีเริ่มต้น **admin / caogikojt02** (เปลี่ยนรหัสผ่านหลังเข้าครั้งแรก)

**ไฟล์ควบคุม (คลิกขวา → Run as administrator)**

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `install-server.bat` | ติดตั้ง/เปิดพอร์ต/ตั้งให้รันอัตโนมัติ/เริ่มระบบ |
| `restart-server.bat` | เริ่มระบบใหม่ (เช่น หลังแก้ `config.json`) |
| `uninstall-server.bat` | หยุดระบบและยกเลิกการรันอัตโนมัติ (ข้อมูลไม่หาย) |
| `start.bat` | เปิดแบบมีหน้าต่าง สำหรับทดลอง (ปิดหน้าต่าง = ระบบหยุด) |
| `logs\server.log` | บันทึกการทำงาน/ข้อผิดพลาด |

**แนะนำเพิ่มเติม**
- กำหนด **IP คงที่ (Static IP)** ให้เครื่องแม่ข่าย มิฉะนั้นลิงก์และ iframe จะใช้ไม่ได้เมื่อ IP เปลี่ยน
- ถ้ามี DNS ภายใน ขอชื่อ เช่น `display.udtc.local` ชี้มาที่เครื่องแม่ข่าย แล้วกรอกในหน้าตั้งค่า
- ถ้ามี Firewall/อุปกรณ์เครือข่ายกลาง ต้องอนุญาตพอร์ต TCP ที่ใช้ด้วย
- Linux: `./start.sh` หรือทำเป็น systemd service (`ExecStart=/usr/bin/node /opt/udtc-display/server.js`)

## 2. ส่วนประกอบของระบบ

| ส่วน | ลิงก์ | ใช้ทำอะไร |
|---|---|---|
| ส่วนแสดงผล (Widget) | `/embed/<slug>` | ชิ้นส่วนที่นำไปฝังด้วย iframe ในเว็บไซต์หลัก |
| ดูทั้งหมด | `/embed/<slug>?full=1` | แสดงรายการทั้งหมด ไม่จำกัดจำนวน |
| หน้าเว็บเผยแพร่ | `/p/<slug>` | หน้าเว็บเต็มรูปแบบ มีเมนู/หัว/ท้ายเว็บ |
| หน้าแรก | `/` | รายการหน้าเว็บทั้งหมด หรือกำหนดให้เป็นหน้าใดหน้าหนึ่ง |
| หน้า Intro | `/intro` หรือ `/intro/<slug>` | หน้าแรกเต็มจอพร้อมแถบปุ่ม |
| หลังบ้าน | `/admin` | จัดการทั้งหมด |

### ส่วนแสดงผล รองรับ
- รูปแบบ: **สไลด์** (เลื่อนอัตโนมัติ, ลูกศร, จุด, ปัดบนมือถือ), **กริด**, **รายการลิงก์**, **ผืนผ้าใบอิสระ (ลากวาง)**, **แท็บ (รวมหลายส่วน)**
- รายการ: **ภาพ**, **วีดีโอ** (YouTube / Facebook / ไฟล์ mp4), **ปุ่มลิงก์**, **HTML**
- **จำกัดจำนวนที่แสดง + ปุ่ม “ดูทั้งหมด”** (แก้ปัญหาภาพเยอะเกินไป)
- กำหนด **วันเริ่ม–สิ้นสุด** การแสดงผลของแต่ละรายการ (ซ่อนอัตโนมัติเมื่อหมดอายุ)
- อัปโหลดหลายภาพพร้อมกัน, ลากจัดลำดับ, เปิด/ปิดรายการ
- ปรับคอลัมน์ (จอใหญ่/มือถือ), สัดส่วนภาพ, ระยะห่าง, มุมโค้ง, เงา, สี
- ตัวอย่างการแสดงผลทันที (เดสก์ท็อป / แท็บเล็ต / มือถือ)

### ตัวออกแบบปุ่ม (🎨 ออกแบบปุ่ม)
- ไอคอน **Font Awesome 6** (ค้นหาได้ทั้งภาษาอังกฤษและไทย เช่น “ศาล”, “ประกาศ”, “ปฏิทิน” หรือพิมพ์ class เอง เช่น `fa-solid fa-gavel`)
- สไตล์สำเร็จรูป 12 แบบ + **บันทึกเป็น “สไตล์ของฉัน”** เพื่อนำไปใช้ซ้ำกับปุ่มอื่น / ใช้สไตล์เดียวกับทุกปุ่มได้ในคลิกเดียว
- สีพื้น / ไล่สี / โปร่งใส, สีตัวอักษร, สีไอคอน, ตำแหน่งไอคอน (ซ้าย ขวา บน ไอคอนอย่างเดียว)
- มุม **เหลี่ยม – มน – แคปซูล**, เส้นขอบ, **นูน 3 มิติ / ยุบลง**, เงา 5 ระดับ
- เอฟเฟกต์เมื่อเอาเมาส์ชี้: ยกลอย, ขยาย, กดลง, **เด้ง (bounce)**, เต้น, สั่น, เรืองแสง, แสงวิ่งผ่าน, สลับสี ฯลฯ
- ภาพเคลื่อนไหวตลอดเวลา: เต้น, ลอย, เรืองแสง, แสงวิ่ง (ปิดอัตโนมัติสำหรับผู้ที่ตั้งค่าลดการเคลื่อนไหวในเครื่อง)

### ผืนผ้าใบอิสระ (Canvas) — ลากวางบนเส้นตาราง
- กำหนดขนาดหน้าเองได้ (เช่น 1200×400) หรือเลือกขนาดสำเร็จรูป และกำหนดขนาดช่องตาราง 5–50px
- **ลากปุ่มไปวางแล้วตำแหน่งจะยึดตามเส้นตาราง** · ลากจุดที่มุม/ขอบเพื่อยืดหดขนาด · **ล็อกตำแหน่ง** ไม่ให้เลื่อนโดยไม่ตั้งใจ
- พิมพ์ค่า X / Y / กว้าง / สูง ได้ตรงๆ, ทำสำเนา, ซ้อนหน้า–หลัง, ใช้ลูกศรบนคีย์บอร์ดเลื่อนทีละช่อง
- วางได้ทั้งปุ่ม ข้อความ และภาพ · ย่อ–ขยายตามความกว้าง iframe โดยคงสัดส่วน · บนมือถือเรียงเป็นแนวตั้งอัตโนมัติ (ปิดได้)

### วีดีโอจาก URL
- วางลิงก์ได้เลยในรายการประเภท “วีดีโอ” (ทุกเลย์เอาต์) หรือปุ่ม **วีดีโอ** บนผืนผ้าใบ: YouTube (วีดีโอ/Shorts/Live/Playlist, ลิงก์ที่มี ?t= เริ่มตามเวลา), Facebook (วีดีโอ/Reels/fb.watch), TikTok, Instagram Reels, Vimeo, Google Drive, Dailymotion, Streamable, ไฟล์ .mp4/.webm, สตรีม .m3u8 หรือโค้ดฝัง `<iframe>` จากเว็บอื่น
- ระบบบอกว่าตรวจพบแหล่งอะไร พร้อมข้อควรระวัง · ปุ่ม “โหลดตัวอย่าง” ทดลองเล่น
- ตัวเลือก: เล่นอัตโนมัติ (ปิดเสียงให้), ปิดเสียง, วนซ้ำ, ปุ่มควบคุม, เริ่มเล่นที่ (นาที:วินาที), สัดส่วนกรอบ (อัตโนมัติ = Shorts/TikTok/Reels เป็นแนวตั้ง 9:16)

- **กรอบและแถบหัวข้อ** (ปุ่ม “🎨 ออกแบบกรอบ / แถบหัวข้อ” ในรายการวีดีโอ): ชื่อเรื่อง + คำอธิบายรอง + ไอคอน, แถบด้านบน/ล่าง, สี/ไล่สี/ฟอนต์/ขนาด/ความสูงแถบ, เส้นขอบ มุมมน เงา พื้นหลังและระยะรอบวีดีโอ, ความกว้างสูงสุด + จัดตำแหน่ง, ธีมสำเร็จรูป 6 แบบ
- กดแถบเพื่อ **ยุบ/ขยาย** (เลือกเริ่มแบบเปิด หรือยุบไว้แสดงแค่แถบ) · ยุบแล้ววีดีโอหยุดเล่น · เริ่มแบบยุบ ตัวเล่นยังไม่โหลดจนกว่าจะกดเปิด

### เส้นขอบปุ่มภาพ (กริด / สไลด์)
- แท็บ “รูปแบบการแสดงผล” → หัวข้อ **เส้นขอบปุ่มภาพ / เอฟเฟกต์เมื่อชี้เมาส์**: แสดงตลอด หรือเฉพาะเมื่อชี้เมาส์ · ใช้เฉพาะภาพที่มีลิงก์ หรือทุกภาพ
- ปรับสีปกติ/สีเมื่อชี้เมาส์ ความหนา ระยะเข้าด้านใน ลายเส้น (ทึบ ประ จุด คู่)
- Animation: เรืองแสง, คลื่นกระจาย, เส้นไล่สีวิ่งรอบ, ยกลอย, ซูมภาพ · บนมือถือโหมด “เฉพาะเมื่อชี้เมาส์” แสดงเส้นขอบตลอด

### QR Code — สร้างและออกแบบในระบบ (ไม่ใช้บริการภายนอก)
- เพิ่มได้จากปุ่ม **QR Code** บนแถบเครื่องมือผืนผ้าใบ หรือ “เพิ่มรายการ → QR Code” ในเลย์เอาต์อื่น · ดับเบิลคลิกเพื่อแก้ไข
- ประเภทข้อมูล: ลิงก์เว็บ, ข้อความ (ภาษาไทยได้), โทรออก, SMS, อีเมล, LINE, Wi‑Fi, แผนที่ Google Maps
- ออกแบบ: ธีมสำเร็จรูป 7 แบบ, สีเดียว/ไล่สี, รูปทรงจุด 5 แบบ (สี่เหลี่ยม มุมมน จุดกลม เพชร แท่งตั้ง), ตามุม 4 แบบ + สีตามุมแยก, พื้นหลังสี/โปร่งใส, ขอบว่าง, มุมมน
- **โลโก้ตรงกลาง**: เลือกจากคลังสื่อ ปรับขนาด 8–32%, พื้นรองมุมมน/วงกลม/สี่เหลี่ยม · ระบบตั้งระดับแก้ไขข้อผิดพลาดเป็น H (30%) และเว้นจุดใต้โลโก้ให้อัตโนมัติ
- ป้าย “สแกนเลย” ด้านบน/ล่าง, คำบรรยายใต้ QR, ลิงก์เมื่อคลิก · ดาวน์โหลด PNG 1024/2048px หรือ SVG สำหรับงานพิมพ์
- มีกล่องตรวจสอบบอกเวอร์ชัน QR และเตือนเมื่อสีกลับ/สีใกล้กัน/โลโก้ใหญ่เกิน — ควรทดลองสแกนด้วยมือถือก่อนใช้จริง

### ภาพและลิงก์ในตาราง
- **ตารางบนผืนผ้าใบ**: ทุกอย่างย่อ–ขยายตามความกว้างที่แสดงจริง จึงมีค่า “ขนาดขั้นต่ำเมื่อย่อบนจอเล็ก” (ค่าเริ่มต้น 14px) กันตัวอักษรเล็กเกิน · บนมือถือใช้ขนาดจริงที่ตั้งไว้ · ขนาดตัวอักษรปรับได้ถึง 48px
- ในตัวแก้ไขตาราง: คลิกช่อง (วางเคอร์เซอร์) แล้วกด **🖼 แทรกภาพ** — เลือกภาพจากคลังสื่อ กำหนดความกว้าง (px หรือ % ของช่อง) และให้คลิกเปิดภาพเต็ม/ไปลิงก์อื่นได้
- **แทรก QR Code** — สร้าง/ออกแบบ QR (ใส่โลโก้ได้) แล้ววางลงในช่องตารางทันที กำหนดความกว้างและให้คลิกเปิดลิงก์ได้ · วางเคอร์เซอร์บนโค้ด `(qr:…)` ในช่องแล้วกดปุ่มเดิมเพื่อแก้ไข QR นั้น
- **🔗 แทรกลิงก์** — เลือกข้อความในช่องก่อนแล้วกด จะเปลี่ยนข้อความนั้นเป็นลิงก์ · ลิงก์ไปไฟล์ในคลังสื่อ (PDF/แบบฟอร์ม) ได้ · รองรับ https:// , tel: , mailto:
- พิมพ์เองก็ได้: ภาพ `![คำอธิบาย|80](url)` · ลิงก์ `[ข้อความ](url)` · ภาพที่เป็นลิงก์ `[![โลโก้|60](url-ภาพ)](url-ปลายทาง)`

### แท็บ (Tabs) — รวมหลายส่วนแสดงผลไว้ในชุดเดียว
- เช่น แท็บ “บริการประชาชน / บริการวิชาการ” แต่ละแท็บกำหนดสีเองได้
- ในแต่ละแท็บ นำส่วนแสดงผลที่สร้างไว้มาวางเรียงกัน กำหนดความกว้างได้ (1/4, 1/3, 5/12, 1/2, 7/12, 2/3, 3/4, เต็ม) เช่น แบนเนอร์ซ้าย 5/12 + ปุ่มขวา 7/12 แล้วแถบ QR เต็มความกว้างด้านล่าง
- แถบแท็บ 3 แบบ: กล่องแคปซูล / ปุ่มแยก / ขีดเส้นใต้ · บนมือถือเนื้อหาเรียงต่อกันลงมาอัตโนมัติ

### ตัวเลือกเพิ่มเติมของกริด/การ์ด
- ปุ่มใช้ **ภาพ/โลโก้แทนไอคอน** ได้ (เช่น โลโก้ระบบ e-Filing) · กำหนดความสูงขั้นต่ำของปุ่มให้เท่ากันทั้งแถว
- รูปแบบหัวข้อ: แถบซ้าย / **แคปซูลกลาง** (แบบ “Infographics”) / กึ่งกลาง+ขีด / ข้อความ
- ระยะขอบรอบภาพ (เหมาะกับโลโก้, QR Code) · จัดคำบรรยายกึ่งกลาง · สีชื่อภาพ · ความมนของกรอบพื้นหลังทั้งชุด
- **ลิงก์ที่ 2 ใต้ภาพ** (เช่น “ดาวน์โหลดแบบฟอร์ม”) · **คลิกภาพเพื่อขยายดู** (แสดงบนหน้าเว็บหลักเมื่อใช้โค้ดฝังแบบปรับความสูงอัตโนมัติ)
- ปุ่ม **“เพิ่มชุดตัวอย่าง”** ในหน้าส่วนแสดงผล: ตัวอย่างปุ่มโลโก้ระบบออนไลน์, แท็บบริการ, QR Code, Infographics และหน้า “ตัวอย่างหน้าบริการ”

### หน้า Intro (เมนู “หน้า Intro”)
- เปลี่ยนภาพ Intro ได้ทั้งภาพจอคอมพิวเตอร์และภาพมือถือแยกกัน · การแสดงภาพ: **เต็มจอพอดี** / เห็นครบทั้งภาพ (พื้นหลังเบลอจากภาพเดียวกัน) / ยืดเต็มจอ / เต็มความกว้าง · จุดยึดภาพ · ภาพซูมช้าๆ · ชั้นสีทับภาพ · ข้อความบนภาพ
- **แถบชุดปุ่ม** วางล่าง/กลาง/บน · พื้นกระจกฝ้า/สีทึบ/ไม่มี · ขนาดปุ่ม จำนวนคอลัมน์ และแบบมือถือ
- **เพิ่ม–ลบ–จัดลำดับปุ่ม** ออกแบบปุ่มด้วยตัวออกแบบเดิม + **เลือกฟอนต์ไทย** (Kanit, Prompt, Sarabun, Mitr, Noto Sans Thai ฯลฯ)
- **ปุ่มเมนูย่อย (Drop Down)** เปิดขึ้นด้านบนเมื่อแถบอยู่ล่าง ใช้ได้ทั้งเมาส์ ทัชสกรีน และคีย์บอร์ด
- **แอนิเมชันเมื่อโหลดหน้า**: แถบลอยขึ้นจากล่าง/ตกลงจากบน/ขยาย/ค่อยๆ ปรากฏ · ปุ่มทยอยลอยขึ้น/เด้ง/พลิก/เลื่อน · ตั้งเวลาเริ่ม ความเร็ว และระยะห่างระหว่างปุ่ม
- ทำสำเนาไว้หลายแบบตามวาระ แล้ว “ตั้งเป็นหลัก” เพื่อสลับ (ลิงก์ `/intro` แสดงหน้าหลักเสมอ) · เข้าสู่เว็บไซต์อัตโนมัติเมื่อครบเวลา (เลือกได้)
- **นำไปใช้**: ดาวน์โหลด `index.html` ไฟล์เดียวที่ฝังภาพไว้แล้ว (แนะนำ — ไม่เรียกเครื่องแม่ข่ายภายใน) หรือใช้ลิงก์ `/intro/<slug>` / โค้ด iframe เต็มจอ
- ปุ่ม/เมนูบนหน้า Intro เปิดหน้าปลายทางแบบ **ทั้งหน้าต่าง** (target=_top) แม้ Intro ถูกฝังใน iframe — URL บนแถบที่อยู่จะเปลี่ยนเป็นหน้าหลัก กด Refresh แล้วไม่ย้อนกลับมา Intro · ถ้าใช้ “เข้าสู่เว็บไซต์อัตโนมัติ” ร่วมกับ iframe ให้ใช้โค้ดฝัง 2 บรรทัด (มีบรรทัด `<script>`) จากปุ่ม “นำไปใช้”

### หน้าเว็บเผยแพร่ รองรับบล็อก
หัวข้อ · ข้อความ · ภาพ · วีดีโอ · ปุ่มลิงก์ · ส่วนแสดงผล · กล่องประกาศ · ไฟล์เอกสาร (PDF/Word/Excel) · HTML · เส้นคั่น
พร้อมสถานะ ฉบับร่าง/เผยแพร่, ภาพปก, เมนูด้านบน

## 3. การฝังในเว็บไซต์หลัก

ในหลังบ้าน กดปุ่ม **“โค้ดฝัง”** ของส่วนแสดงผล แล้วคัดลอกไปวาง

แบบปรับความสูงอัตโนมัติ (แนะนำ):
```html
<iframe src="http://IP-เครื่องแม่ข่าย:8090/embed/pr-banner" data-uw-embed style="width:100%;border:0;display:block" height="420" loading="lazy"></iframe>
<script src="http://IP-เครื่องแม่ข่าย:8090/assets/embed.js" async></script>
```

แบบความสูงคงที่ (กรณีเว็บปลายทางใส่ `<script>` ไม่ได้):
```html
<iframe src="http://IP-เครื่องแม่ข่าย:8090/embed/pr-banner" width="100%" height="420" style="border:0"></iframe>
```

> ⚠ ถ้าเว็บไซต์หลักเป็น **https** ระบบนี้ควรเปิดผ่าน **https** ด้วย มิฉะนั้นเบราว์เซอร์จะบล็อก iframe (mixed content) — ทำได้โดยวางหลัง reverse proxy ที่มีใบรับรอง SSL หรือขอโดเมนย่อยจากผู้ดูแลเครือข่าย

## 3.1 ส่งออกโค้ด HTML + CSS (ไม่ใช้ iframe)

กดปุ่ม **“ส่งออก HTML + CSS”** ในหน้าแก้ไขส่วนแสดงผล (หรือปุ่ม **HTML** ในรายการ) แล้วคัดลอกโค้ดไปวางในหน้าเว็บได้ทันที
- HTML + CSS อยู่ในชุดเดียว (แบบสไลด์จะมี `<script>` เล็กๆ ต่อท้ายเพื่อเลื่อนภาพ)
- CSS ถูกจำกัดให้มีผลเฉพาะส่วนนี้ (ขึ้นต้นด้วย `#uwx-ชื่อslug`) จึงไม่กระทบหน้าตาส่วนอื่นของเว็บ และกันไม่ให้ CSS ของเว็บปลายทางมาเปลี่ยนหน้าตาปุ่ม
- ปรับรูปแบบตาม **ความกว้างของช่องที่วาง** (เช่น วางในแถบข้างแคบๆ ปุ่มจะเรียงแนวตั้งเหมือนบนมือถือ)
- มีหน้าทดลองวางในเว็บจำลอง (เต็ม / คอลัมน์กลาง / แถบข้าง) และดาวน์โหลดไฟล์ .html ไว้ทดสอบได้

ข้อควรรู้: โค้ดเป็น **สำเนา ณ ตอนส่งออก** — แก้ไขในหลังบ้านแล้วต้องส่งออกและวางใหม่ · ระบบวันเริ่ม–สิ้นสุดการแสดงผลจะไม่ทำงานในโค้ดที่ส่งออก · ภาพยังโหลดจากเครื่องแม่ข่าย · บางระบบจัดการเนื้อหาอาจตัดแท็ก `<style>`/`<script>` ออก ให้วางในโหมด HTML/Source

## 4. ข้อมูลและการสำรอง

- ข้อมูลทั้งหมด: `data/db.json`
- ไฟล์ที่อัปโหลด: `uploads/`
- สำรอง: คัดลอก 2 โฟลเดอร์นี้ไว้ หรือกด “ดาวน์โหลดไฟล์สำรอง” ที่หน้า **ตั้งค่าเว็บไซต์**
- ลืมรหัสผ่าน admin: หยุดระบบ → เปลี่ยนชื่อไฟล์ `data/db.json` → เปิดใหม่ (ระบบจะสร้างข้อมูลเริ่มต้นพร้อมบัญชี admin ใหม่) แล้วกู้คืนข้อมูลจากไฟล์สำรองตามต้องการ

## 5. หมายเหตุ

- หน้าหลังบ้านและหน้าเว็บเผยแพร่โหลด TailwindCSS, SweetAlert2, Font Awesome และฟอนต์ Sarabun จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต (ส่วนแสดงผล iframe ใช้ CSS ของระบบเอง ทำงานได้แม้ฟอนต์โหลดไม่ได้)
- ไฟล์ที่อัปโหลดได้: ภาพ (jpg, png, gif, webp, svg), วีดีโอ (mp4, webm, mov), เอกสาร (pdf, doc(x), xls(x), ppt(x), zip, txt) ขนาดสูงสุด 200MB ต่อไฟล์
- สิทธิ์ผู้ใช้: **ผู้ดูแลระบบ** จัดการได้ทั้งหมด / **ผู้แก้ไขเนื้อหา** จัดการส่วนแสดงผล หน้าเว็บ และคลังสื่อ
